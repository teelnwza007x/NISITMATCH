Nisit Match — แก้หน้าโปรไฟล์คู่ Match และปุ่มกลับไปข้อความล่าสุด

- กดชื่อ/รูปของคู่ Match ในหัวแชตเพื่อเปิดโปรไฟล์
- ดูรูปทั้งหมดด้วยปุ่มเลื่อนหรือรูปย่อ และดูเพลงที่เจ้าของโปรไฟล์เลือก
- แก้ z-index ของหน้าต่างโปรไฟล์ให้แสดงเหนือแชตเต็มจอ
- เลื่อนแชตขึ้นเกิน 75px จะมีปุ่มกลับไปข้อความล่าสุดด้านล่างตรงกลาง
- กดปุ่มแล้วเลื่อนลงแบบ smooth; ถ้าอ่านย้อนหลังอยู่ ข้อความใหม่จะไม่บังคับเลื่อนลง

วิธีติดตั้ง: สำรองไฟล์เดิม จากนั้นแทน src/App.jsx และ src/styles.css ด้วยไฟล์ใน ZIP
รัน npm install และ npm run build ในเครื่องของคุณ
ไม่ต้องรัน SQL เพิ่ม
หมายเหตุ: ถ้า Supabase RLS ไม่อนุญาตให้ดึง profiles ของคู่ Match บางราย รูป/เพลงอาจไม่แสดง
